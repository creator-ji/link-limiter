О проекте
Сервис сокращения ссылок — это инструмент, который позволяет пользователю сократить длинный URL, получить уникальную короткую ссылку и управлять её параметрами.

Пользователь может устанавливать лимит на количество переходов по ссылке и отслеживать её активность. После достижения лимита переходов или истечения заданного срока ссылка станет недоступной, и пользователь получит уведомление с предложением создать новую ссылку.
